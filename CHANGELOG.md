# Release Notes

## [Unreleased](https://github.com/bumbummen99/laravel-versioned-storage/commits/master)

### Added

- Versioned files and directory snapshots with database-backed publication.
- Staged uploads with transactional publication and permanent UUID reservations.
- Durable operation journals, bounded filesystem execution, and recovery deadlines.
- Scheduled cleanup for interrupted uploads and retired versions.
- Laravel configuration, migration publishing, and application testing helpers.
- Real-process timeout and crash-recovery tests, including PHP-FPM/Nginx coverage.
